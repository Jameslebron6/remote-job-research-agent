### 3. 用自己的话回答

1. 为什么 created 比 start 先打印？
因为调用生成器只是调用他，并没有进入内部执行，之后next执行后才继续进行下面的执行操作

标准答案
调用 numbers() 时，会创建并返回一个生成器对象，但暂不执行函数体。第一次调用 next(values) 时，才从函数体开头执行，直到遇到 yield 暂停。

2. 为什么同一个生成器第二次转换成列表会得到 []？
因为第一次已经把内部给执行完了，第二次转换成列表，只会执行里面的空操作
标准答案
第一次 list(values) 已经把生成器消耗完。第二次仍然使用同一个已耗尽的生成器，没有剩余元素可收集，所以得到空列表。

3. 如果想重新得到 1、2，应该重新创建什么？
在创建一个新的生成器对象
比如 下面这样
def main() -> None:
    values = numbers()
    values2=numbers()
    first = list(values)
    second = list(values2)

    print("first:", first)
    print("second:", second)
