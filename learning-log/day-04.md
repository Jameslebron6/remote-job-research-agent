## 我的理解

1. dict 和 set 在今天的代码里分别保存什么？
dict 保存的是字典类型key,value类型 set保存的是去除重复后的只

今天的 dict 保存“技能名称 → 出现次数”，例如 {"python": 2}。
set 保存已经遇到过的技能名称，例如 {"python", "go"}，用于判断某个技能是否已经出现，不保存次数。
2. counts.get(skill, 0) 中的 0 起什么作用？
如果没有对应的值的话，返回的默认值
当字典中不存在 skill 这个键时，返回默认值 0。这样第一次遇到技能时，就可以从 0 开始加一。
3. 为什么保序去重同时使用 seen 和 result？
因为seen用于将数据去重，然后保证顺序需要一步一步往里加，seen不保证顺序
seen 用于判断技能是否已经出现；`result` 用于保存首次出现的技能及其顺序。按照原列表依次遍历，只有没见过的技能才加入 result，因此既去重，又保留首次出现顺序。
4. 为什么 list(set(skills)) 不能保证首次出现顺序？
因为set只去重，但是不保证顺序
因为集合不保证保留输入元素的顺序。转换成列表时，得到的是集合的遍历顺序，不能恢复原列表中首次出现的顺序。
5. 为什么计数之前不能先去重？
肯定，去重就计数不对了
去重会丢失重复出现的信息，导致后续无法计算原始出现次数。
